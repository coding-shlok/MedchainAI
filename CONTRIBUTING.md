# Contributing to MedChain AI

Thank you for your interest in contributing! This project is a research artifact published for academic review and reproducibility. 

## How to Contribute

### Reporting Issues

If you find a bug or have a suggestion:
1. Check existing issues first
2. Open a new issue with:
   - Clear title and description
   - Steps to reproduce (for bugs)
   - Expected vs. actual behavior
   - Your environment (Python version, GPU, OS)

### Making Changes

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Test thoroughly
5. Commit with clear messages: `git commit -m "Fix/Feature: description"`
6. Push and open a pull request

### Code Style

- **Python:** PEP 8 (use `black` for formatting)
- **JavaScript:** Standard (4-space indentation)
- **Documentation:** Markdown with clear section headers

### Testing

Before submitting a PR:
- Run classification on a small config
- Test blockchain auditor
- Verify paper regeneration (if docs changed)

## Project Scope

This is a published research project. Contributions should:
- Improve reproducibility or clarity
- Fix bugs
- Add evaluation on real/new datasets (with clear methodology)
- Enhance documentation

Contributions that significantly alter the core results or claims should be discussed in an issue first.

## Citation

If your contribution is substantial, feel free to ask about co-authorship acknowledgment.
